Нативный Wi-Fi macOS для карт Intel, от 802.11n до Wi-Fi 7

macOS Tahoe 26 и Sequoia 15 · WPA3 · 6 ГГц · 802.11be · BE200 / BE201 и все карты, которые поддерживает itlwm

AirportItlwm, доведённый от Wi-Fi 6 до Wi-Fi 7 (BE200, BE201); AirDrop и Instant Hotspot в разработке. Все ранее поддерживаемые карты продолжают работать на штатном Wi-Fi macOS, без HeliPort.

Происхождение и благодарности

Этот проект существует только благодаря чужому исходному коду. Он сохраняет всё из itlwm и AirportItlwm и дополняет это, а не заменяет. Спасибо всем, кто назван ниже.

  1. itlwmzxystd / OpenIntelWireless
  2. laobamac/itlwmНативный беспроводной интерфейс Apple для Tahoe/Sequoia
  3. Eric-AirportItlwmЭтот репозиторий

itlwm от zxystd / OpenIntelWireless → laobamac/itlwm (нативный беспроводной интерфейс Apple для Tahoe/Sequoia) → этот репозиторий: сохраняет всё перечисленное и добавляет транспорт Wi-Fi 7 и путь прошивки MLD, WPA3 SAE/H2E и OWE, 6 ГГц, 320 МГц и multi-link, реализуя команду за командой по Linux iwlwifi (mld, mvm) и mac80211.

Установка

  1. Скачайте в Releases пакет для вашей macOS: macOS26-Tahoe для macOS 26, macOS15-Sequoia для macOS 15.2 и новее. Release — для повседневной работы; Debug сохраняет диагностические журналы, нужные для отчёта.
  2. Положите кекст в EFI/OC/Kexts/ и добавьте его в Kernel → Add. Оставьте только один кекст Wi-Fi от Intel. Если одна конфигурация загружает обе системы, ограничьте кекст для Tahoe версиями Darwin 25.0.0–25.99.99, а для Sequoia — 24.2.0–24.99.99.
  3. Не сочетайте его с root-патчами «Modern Wireless» из OpenCore Legacy Patcher и любой заменой IO80211 / Skywalk: этот драйвер использует собственный стек Wi-Fi системы.
  4. Сохраните загрузочную копию своего EFI и сначала проверьте всё с USB-накопителя.

Страна и разрешённые в ней каналы определяются по окружающим сетям с помощью собственной логики регулирования карты, как в Linux. Ничего настраивать не нужно.

🧪 В разработке

Instant Hotspot

Пробуждение точки доступа iPhone по Bluetooth, направленное сканирование и ассоциация WPA3 работают; сейчас iPhone разрывает связь сразу после четырёхстороннего рукопожатия. Это открытая ошибка, и исправление будет действовать для всех карт.

AirDrop (AWDL)

awdl0 создаётся, и им управляет собственный стек AWDL macOS. Для AirDrop карта должна слушать канал AWDL, оставаясь в вашей сети. У всех карт Intel, кроме AX411, один радиомодуль (eMLSR в Wi-Fi 7 — тоже один радиомодуль), поэтому прошивка делит время между ними:

  • Карты AX (прошивка без MLD): постоянный слушатель с собственным контекстом канала — та же конструкция, которую ForbiddenItlwm запускает на AX211, с AirDrop в обе стороны.
  • Карты BE (прошивка MLD): та же идея на наборе команд MLD — линк P2P-клиента рядом с линком станции (сочетание, которое Linux допускает на двух каналах). Правила активации прошивки выясняются по её собственному коду; пока не работает.
  • AC и старше: не планируется.

Сначала в macOS должны работать рекламные пакеты и сканирование Bluetooth LE. Тестовые пакеты содержат подходящий BlueToolFixup с -btlfxadvsets (наборы LE-рекламы для сторонних контроллеров, macOS 26.4–26.7.3) и -btlfxrpa (подключение к iPhone с приватным адресом; пока macOS 26.4 и 26.7). С -itlawdl драйвер сначала проверяет, что таблица интерфейса AWDL от Apple имеет ту раскладку, под которую он собран (AWDLBuildCheck в I/O Registry), и иначе работает как обычный Wi-Fi, так что обновление macOS не приведёт к kernel panic. Канал прослушивания — 149, затем 44, затем 6, причём только тот, на котором страна разрешает передачу (44 там, где нет 149; пассивный канал — после того как рядом услышан роутер, передающий на нём маяки). Быстрее всего 149: роутеры на 149 и iPhone на 149 или без Wi-Fi дают лучшую скорость AirDrop.

Сообщить о проблеме

Используйте пакет Debug. Воспроизведите проблему один раз, затем запустите Collect-WiFi-Community.command из пакета и приложите архив к issue на GitHub, указав карту, сборку macOS, модель роутера, режим защиты и свои действия. Для роутера Wi-Fi 7 укажите, включён ли MLO и какие диапазоны он объединяет. В архиве есть метаданные сети: при желании отправьте его лично. Сборка, которая компилируется, ещё не результат; напишите, что вы увидели на своей машине.
