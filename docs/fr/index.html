Le Wi-Fi natif de macOS pour les cartes Intel, du 802.11n au Wi-Fi 7

macOS Tahoe 26 et Sequoia 15 · WPA3 · 6 GHz · 802.11be · BE200 / BE201 et toutes les cartes prises en charge par itlwm

AirportItlwm porté du Wi-Fi 6 au Wi-Fi 7 (BE200, BE201), avec AirDrop et le point d'accès instantané en cours de développement. Toutes les cartes déjà prises en charge continuent de fonctionner, avec le Wi-Fi propre à macOS et sans HeliPort.

Installation

  1. Téléchargez le paquet correspondant à votre macOS depuis Releases : macOS26-Tahoe pour macOS 26, macOS15-Sequoia pour macOS 15.2 ou ultérieur. Release pour un usage quotidien ; Debug conserve les journaux de diagnostic dont un rapport a besoin.
  2. Placez la kext dans EFI/OC/Kexts/ et ajoutez-la dans Kernel → Add. N'utilisez qu'une seule kext Wi-Fi Intel. Si une même configuration démarre les deux systèmes, limitez la kext Tahoe à Darwin 25.0.0–25.99.99 et la kext Sequoia à 24.2.0–24.99.99.
  3. Ne la combinez pas avec les correctifs racine « Modern Wireless » d'OpenCore Legacy Patcher ni avec un remplacement d'IO80211 / Skywalk : ce pilote utilise la pile Wi-Fi du système elle-même.
  4. Gardez une copie amorçable de votre EFI et testez d'abord depuis une clé USB.

Le pays et les canaux qui y sont autorisés viennent des réseaux environnants, grâce à la logique de réglementation de la carte elle-même, comme sous Linux. Il n'y a rien à régler.

Continuité

🧪 En développement

Point d'accès instantané

Le réveil Bluetooth du point d'accès de l'iPhone, le balayage dirigé et l'association WPA3 fonctionnent ; pour l'instant, l'iPhone coupe la liaison juste après la poignée de main à quatre voies. C'est le bogue ouvert, et la correction vaut pour toutes les cartes.

AirDrop (AWDL)

awdl0 est créée et c'est la pile AWDL de macOS elle-même qui la pilote. AirDrop exige que la carte écoute sur le canal AWDL tout en restant sur votre réseau. Toutes les cartes Intel sauf l'AX411 n'ont qu'une seule radio (l'eMLSR du Wi-Fi 7 est aussi une radio unique), si bien que le micrologiciel se partage le temps entre les deux :

  • Cartes AX (micrologiciel sans MLD) : un écouteur permanent avec son propre contexte de canal, la construction que ForbiddenItlwm fait tourner sur l'AX211 avec AirDrop dans les deux sens.
  • Cartes BE (micrologiciel MLD) : la même idée avec le jeu de commandes MLD, sous la forme d'un lien client P2P à côté du lien station (la combinaison que Linux autorise sur deux canaux). Les règles d'activation du micrologiciel sont en cours d'élucidation à partir de son propre code ; ne fonctionne pas encore.
  • AC et plus anciennes : non prévu.

La publicité et le balayage Bluetooth LE doivent d'abord fonctionner sous macOS. Les paquets de test embarquent un BlueToolFixup assorti avec -btlfxadvsets (ensembles de publicité LE pour contrôleurs tiers, macOS 26.4–26.7.3) et -btlfxrpa (connexion à un iPhone qui utilise une adresse privée ; macOS 26.4 et 26.7 pour l'instant). Avec -itlawdl, le pilote vérifie d'abord que la table d'interface AWDL d'Apple a la disposition pour laquelle il a été compilé (AWDLBuildCheck dans l'I/O Registry), sinon il fonctionne comme un simple Wi-Fi : une mise à jour de macOS ne peut donc pas provoquer de kernel panic. Le canal d'écoute est 149, puis 44, puis 6, et seulement un canal sur lequel le pays autorise l'émission (44 là où il n'y a pas de 149 ; un canal passif dès qu'un routeur voisin y émet des balises). Le 149 est le plus rapide : routeurs sur 149 et iPhone sur 149 ou hors Wi-Fi donnent la meilleure vitesse AirDrop.

Signaler un problème

Utilisez le paquet Debug. Reproduisez le problème une fois, puis lancez Collect-WiFi-Community.command depuis le paquet et joignez l'archive à un ticket GitHub avec votre carte, la version de macOS, le modèle du routeur, le mode de sécurité et ce que vous avez fait. Pour un routeur Wi-Fi 7, indiquez si le MLO est activé et quelles bandes il combine. L'archive contient des métadonnées réseau : envoyez-la en privé si vous préférez. Une version qui compile n'est pas un résultat ; dites ce que vous avez observé sur votre machine.
